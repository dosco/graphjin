<section id="engine" class="dx-value"><div class="dx-value-copy"><p class="dx-kicker"><b>09</b><i></i><span>An open engine underneath</span></p><h2>How a question becomes one database query.</h2><p>The model plans and your database computes. The agent finds the tables a question needs and writes a query for them. The engine checks that query against your access rules and compiles it into a single database query, so the joins, sums and rankings happen in your database, not in the model.</p><p>The engine is open source under Apache 2.0, and you can use it without the agent, as an API server or a Go library.</p><div class="dx-links"><a class="dx-more" href="/why/open-engine/">What the engine does on its own</a><a href="/core/compiler/">Compiler docs</a></div></div><div class="dx-value-art">{{< ascii scene="how" label="Animated diagram of one question in seven steps: ask, find the tables in the map, write a query, check it against your access rules, compile it to one SQL statement, run it in your database, and answer with what was run." caption="from a question to one database query" >}}</div></section>
