# Corrugated Plant Prompts

Useful prompts for the running demo:

- Which work orders should the corrugator prioritize today? Use catalog
  discovery first, then run the approved saved query that has plant schedule
  context.
- Which paper rolls are below reorder point, and what should purchasing do?
- Review recent downtime and quality holds. Which line needs attention first?
- Create a watch named `machine_down_watch` that monitors work order status
  and downtime events.
- Inventory the approved saved queries and workflows. Do not execute anything.
